ACS CONSTRUCTION WEBSITE - VERCEL DEPLOYMENT

Files:
- index.html                 Complete website source code
- acs-construction-intro.mp4 Introduction video used by the website
- vercel.json                Vercel static-site configuration

DEPLOY:
1. Extract this ZIP file.
2. Open https://vercel.com and sign in.
3. Choose Add New -> Project.
4. Import the GitHub repository containing these files, OR use Vercel CLI from this folder.
5. For a plain static HTML site, choose Other as the framework preset (if asked).
6. Leave Build Command and Output Directory empty/default; deploy the folder containing index.html.

IMPORTANT:
Keep acs-construction-intro.mp4 in the same folder as index.html. The video path in the HTML is relative.
